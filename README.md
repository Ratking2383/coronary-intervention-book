# Coronary Intervention Living Book

MkDocs Material site for an evolving educational reference on coronary intervention materials, devices, techniques, evidence, and daily news.

## Draft-first editorial workflow

Changes should be prepared in a branch or pull request, reviewed, and merged into `main` only after editorial and medical review. Merging to `main` triggers the GitHub Pages deployment workflow.

## Local preview

```bash
pip install mkdocs-material
mkdocs serve
```

## Disclaimer

This is educational content and does not replace formal training, institutional protocols, manufacturer instructions for use, or current guidelines.
