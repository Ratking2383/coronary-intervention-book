# Calcium Modification and Lesion Preparation

Severe coronary calcium can limit balloon expansion, device delivery, and final stent expansion.

## Assessment

Calcium may be assessed using angiography, fluoroscopy, IVUS, or OCT. Important features include arc, length, depth, concentricity, and nodular calcium.

## Tools

- Noncompliant balloons
- Cutting and scoring balloons
- Rotational atherectomy
- Orbital atherectomy
- Intravascular lithotripsy

## Procedural considerations

The selected tool should match the calcium pattern, vessel size, lesion length, crossing difficulty, clinical urgency, and operator expertise. Potential complications include dissection, perforation, slow flow, no-reflow, arrhythmia, and device entrapment.
